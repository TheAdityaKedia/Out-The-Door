# Doorstep enclosure

3D-printed case for the Elecrow CrowPanel ESP32-S3 2.13" e-paper board:
a seamless white body, a "Slope" front plate, and the orange "Latch" drum that turns the CrowPanel's wheel.

Printed on a Bambu Lab X2D (PLA, white + orange).
